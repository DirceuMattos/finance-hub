# Finance Hub

Quero construir um sistema web responsivo de controle financeiro pessoal e empresarial conectado a um banco Supabase já existente.

Neste momento, não quero que você recrie a modelagem do banco nem proponha novas tabelas. Quero apenas criar a estrutura inicial do app consumindo o banco já existente.

Objetivo desta primeira etapa:

- conectar ao Supabase

- criar layout geral

- criar navegação lateral

- criar páginas iniciais vazias e organizadas

- preparar componentes reutilizáveis de tabela, filtros e formulários

Criar as páginas:

- Dashboard

- Lançamentos

- Recorrências

- Cartões

- Compras no Cartão

- Faturas Projetadas

- Fluxo Mensal

- Configurações

Agrupar navegação em:

- Visão Geral

- Financeiro

- Cartões

- Configurações

Quero um layout clean, executivo, com boa legibilidade em desktop, cards simples, tabelas filtráveis e formulários em drawer ou modal.

Não implemente ainda regras complexas de negócio. Foque apenas em:

- estrutura visual

- navegação

- conexão com dados

- leitura básica das tabelas existentes no Supabase
